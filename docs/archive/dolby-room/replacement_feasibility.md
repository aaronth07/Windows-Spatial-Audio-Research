# Native room-response replacement

The mapped native topology represents a constrained artificial reverberator independently of the primary personalized directional PCA filters. Native output-tap muting and half-feedback decay replacement have now been tested with directional coefficients preserved, including an existing object stream. Verified results and controls. The earlier offline proposal details below remain useful for representation limits and a possible calibrated design.

The payload does not provide an evidenced arbitrary measured stereo-FIR, multi-position BRIR or direction-dependent reflected-field importer. Its finite recursive topology and common room excitation cannot exactly represent a general supplied sample sequence or independent per-source room responses. The demonstrated replacement changes the native parametric decay while retaining its topology, delays, diffusion and stereo coloration; a user-specified physical room is not implemented.

Inspection records the decoded owned parameters, a numerical decay fixture, preservation hashes, and local asset comparison. Inspector reads the existing files and emits JSON; it does not export coefficients or use a Windows audio/native-library API. Tests supplement the existing payload tests. The retained native dossiers and parameter map provide the shipped-code evidence. Shared REA remained with the primary's Sonic investigation; this pass used retained evidence and pure Python only.

## Representation and isolation

| Lanes, inclusive | Native room field | Function in selected ordinary branch | Replacement constraints |
|---|---|---|---|
| 14..16 / 17..19 | Input allpass delays/gains | Three cascaded diffusion sections; owned delays 1/2/3, gains 0.75 | Integer delay and signed Q15 gains; preserve initially. Strict gain magnitude below one gives stable individual allpasses. |
| 20 | Scalar +0x1c | Selects an alternative implementation at >=0.5 | Owned zero; preserve. Alternative branch remains outside this model. |
| 21..1044 | Ear-filter pointer +0x20 | Four complex branch weights per ear and band | 64 bands, 4 branches, 2 ears, real/imaginary signed Q15. These are room output spectral weights, not arbitrary time-domain ear FIRs. |
| 1045..1048 | Delay pointer +0x30 | Four feedback delay lines | Owned 25/23/17/8; actual native time units are not independently calibrated. Changing them requires native allocation/index-bound evidence. |
| 1049 | Integer +0x38 | Output state delay | Owned seven. It does not come from the separate +0x28 header value 25. Preserve initially. |
| 1050..1561 | Feedback pointer +0x40 | Four complex feedback factors per band | 512 signed Q15 lanes. Decay and spectral phase are controllable within the feedback network; cannot specify independent arbitrary reflection arrivals. |
| 1562..1577 | Matrix pointer +0x48 | Common real 4x4 branch mixing | Owned Hadamard matrix, all entries +/-0.5, spectral norm exactly one. A new matrix must be assessed jointly with feedback for stability. |
| 1578..1833 | Tap pointer +0x50 | Four real output multipliers per band | 256 signed Q15 lanes; affects room return, not its poles. Zeroing these was the earlier suppression candidate; a replacement needs nonzero designed output. |

Native parser `0x18010fd30` assigns these arrays to the room structure separately from PCA. Native output `0x18001b960` multiplies delayed branch states by taps, applies the room ear filters and adds the sum to existing left/right output. Feedback `0x18001bdf0` reads delays, matrix and feedback. Wrapper `0x18001b700` combines that path with extra contributions from `0x18001bb80`; owned extra-count zero excludes those contributions for this structure. These mappings substantiate room-specific consumers in the selected branch. They do not establish every runtime-selected room pointer or alternative path.

Preserve lane13 shared exponent2, lanes1834..15623 directional PCA and lanes15624..15690 shared trailer/profiles. Distance profiles and header scalars are used by direct rendering as well as room sends. Clear-all-A or changing shared distance fields would violate the required isolation. The HRTF agent independently corroborated the shared exponent and directional complex-field decode; no new dependency on these room arrays was identified.

The public model consumes a common summed room-send signal through this network. Its per-band transfer has four delayed recursive branches, three allpasses, one delayed output stage, and fixed stereo branch weights. It offers a finite constrained rational response rather than an arbitrary sample sequence. Ear coefficients and output taps also have a multiplicative ambiguity: scaling one and inversely scaling the other can produce the same return. A single stereo response cannot uniquely recover every internal parameter. Keep the existing matrix/delays/diffuser and a fixed output-scale convention for a first identification exercise; do not fit all arrays freely.

## Object direction and distance

In the public `rosella_direct.py`, object coordinates are quantized and geometrically mapped through profile axis scales/bounds. Far/mid send is `r / sqrt(1 + c*r*r)`, where effective r also uses shared header/profile scales; near send is zero. Direction can affect the effective radius through anisotropic mapping and bounds, but this implementation does not select a different directional room impulse. A measured radius-only output change alone cannot identify which equation or profile is active.

## Numerical fixture and local asset

The inspector replaces only feedback lanes in memory with real gains `q[j] = round(32768 * exp(-ln(1000)*delay[j]*64/(48000*T))) / 32768`. Imaginary feedback is zero. For nominal T=0.32 seconds the four gains are 0.4869689941, 0.5158081055, 0.6130676270 and 0.7943420410. This assumes a 64-sample public-model slot at 48 kHz; it is not a native T60 calibration or a user-selected room.

With the unchanged unit-norm mixing matrix, the per-band feedback contraction bound is 0.7943420411, below one. Unequal unit-gain delays do not invalidate this sufficient small-gain bound. Existing stable allpasses and finite output filters remain unchanged. A 1536-slot subband impulse is finite, nonzero and differs from the owned return; its final128-slot energy is below 1e-12. Direct gains and room sends are bitwise identical for three positions in each of three public profiles. These are subband-model results, not synthesized PCM, measured native decay or native coefficient acceptance.

The local `output/data/room.npz` is a synthetic legacy Joint-HRTF studio asset: seven sources, seven virtual feeds, fifth-order Ambisonics, nominal320 ms decay, first-order reflections, and HRTF-dependent decoding. Its seven-source stereo reference has rank seven after sample4800 (100 ms assuming48 kHz). The retained singular values are similar in size. This is a representation diagnostic, with direct/HRTF tails still present; it is not an isolated measured room target. A single common scalar-fed stereo return cannot reproduce those seven independent source responses. Reusing that asset's baked HRTF would also compromise preservation of the current personalization. No asset coefficients were copied or fitted.

All12 tests passed with the project's Python3.8 runtime, and both new scripts compiled. Tests cover inverse serialization/quantization at30 ms,320 ms and2 s, invalid/nonfinite parameters, checksum/isolation, CLI success/refusal, source preservation and public-model stability/direct isolation. Review found that20 ms could round a long-delay gain to zero; the fixture now accepts30 ms..2 s and separately rejects nonpositive or noncontractive quantization. The existing eight tap-candidate tests also remain passing. No live settings changed.

## Proposal and native acceptance requirements

For an initial chosen parametric replacement, retain topology/allocation, shared fields and HRTF; design frequency-dependent feedback magnitudes for selected decay, then room ear/tap weights for selected spectrum/stereo balance. A feedback-only change is the smallest useful decay replacement experiment; it retains existing spatial coloration/diffusion and is not a complete physical-room replacement. Changes to reflection timing, diffusion or stereo response need additional room arrays and correspondingly stronger validation. A measured BRIR requires direct-path separation, current-personalization compatibility, and a constrained approximation with held-out positions/signals; reject an unattainable match rather than fitting unidentifiable parameters.

Before export, verify low16 signed-Q15 decoding, padded-grid inverse round trip, coefficient counts/version/ancillary controls, strict contraction for every band, allpass stability, finite bounds, nonzero room output, and unchanged PCA/trailer/exponent.
